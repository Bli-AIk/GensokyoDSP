### 1. a_noise测试 (4个失败)

#### test_a_noise_0_8502
- **相似度**: 83.34% (目标: 95%)
- **差距**: 11.66%
- **问题分析**:
  - 参考包络起音时间: 0.520秒
  - 当前包络起音时间: 0.070秒
  - 包络形状完全不匹配
  - 相关系数为负(-0.75)，表明波形严重不匹配

#### test_a_noise_0_9051
- **相似度**: 79.60%
- **差距**: 15.40%
- **参考包络起音**: 0.450秒

#### test_a_noise_0_9515  
- **相似度**: 92.39%
- **差距**: 2.61%
- **参考包络起音**: 3.980秒（！异常值）

#### test_a_noise_1_0
- **相似度**: 87.73%
- **差距**: 7.27%
- **参考包络起音**: 0.350秒

**根本原因**:
- 高a_noise值需要慢起音包络来避免噪声突发
- 当前实现的包络起音时间固定为0.014秒
- 需要实现动态包络系统，让起音时间随a_noise变化

**解决方案**:
1. 修改envelope.rs的create_envelope函数，添加a_noise参数
2. 当vol_atk=0且a_noise>=0.8时，使用慢起音
3. 起音时间映射:
   - a_noise=0.8080 -> 0.445s
   - a_noise=0.8502 -> 0.520s
   - a_noise=0.9051 -> 0.450s
   - a_noise=0.9515 -> 3.980s
   - a_noise=1.0 -> 0.350s
4. 使用高attack_power (12.0) 产生陡峭曲线

**风险**: 修改包络系统会影响其他测试（已验证：破坏了20个a_color测试）

### 2. b_freq测试 (6个失败)

#### 测试列表与相似度
- test_b_freq_0_4958: 93.31% (差距: 1.69%)
- test_b_freq_0_5506: 91.60% (差距: 3.40%)
- test_b_freq_0_6519: 91.87% (差距: 3.13%)
- test_b_freq_0_8080: 93.36% (差距: 1.64%)
- test_b_freq_0_8502: 90.18% (差距: 4.82%)
- test_b_freq_0_9051: 90.88% (差距: 4.12%)

**问题分析**:
- 所有测试相似度在90-93%之间
- 非常接近95%阈值
- 主要是RMS补偿不够准确

**当前RMS补偿逻辑** (synthesizer.rs:255-275):
```rust
let freq_compensation = if freq_b < 150.0 {
    0.87 + (freq_b - 65.0) / (150.0 - 65.0) * (0.96 - 0.87)
} else if freq_b < 500.0 {
    0.96 + (freq_b - 150.0) / (500.0 - 150.0) * (1.0 - 0.96)
} else if freq_b < 1500.0 {
    1.0
} else if freq_b < 3000.0 {
    1.0 + (freq_b - 1500.0) / (3000.0 - 1500.0) * (1.3 - 1.0)
} else if freq_b < 5000.0 {
    1.3 + (freq_b - 3000.0) / (5000.0 - 3000.0) * (1.6 - 1.3)
} else {
    let base = 1.6;
    let extra = ((freq_b - 5000.0) / 1000.0) * 0.1;
    (base + extra).min(1.8)
};
```

**解决方案**:
- 需要细化中高频段(500-2000Hz)的补偿曲线
- 可能需要根据实际测试数据拟合更精确的补偿函数
